# Checklist de Atividade

Marque `sim`, `não` ou `não se aplica`. Um “não” em item bloqueante impede publicação.

## Experiência

- [ ] O propósito descreve uma experiência, não desempenho? **Bloqueante**
- [ ] A criança pode escolher como participar?
- [ ] A proposta preserva imaginação, exploração ou interação?
- [ ] Há alternativa mais simples?
- [ ] Repetir, mudar o rumo ou encerrar é explicitamente válido? **Bloqueante**
- [ ] O adulto recebe orientação de observar e responder, não testar?
- [ ] Perguntas e prompts são opcionais?

## Adequação

- [ ] Idade mínima/máxima têm justificativa concreta? **Bloqueante**
- [ ] A proposta não exige um marco como pré-condição?
- [ ] Duração, preparo, energia adulta e bagunça são realistas?
- [ ] Faixa ampla possui adaptações reais?
- [ ] Ambiente e quantidade de participantes estão definidos?

## Conteúdo obrigatório

- [ ] Resumo e justificativa de fase
- [ ] Materiais obrigatórios, opcionais e substitutos
- [ ] Preparação
- [ ] Passos flexíveis
- [ ] Prompts de interação
- [ ] Sinais de interesse
- [ ] Sinais para adaptar ou parar **Bloqueante**
- [ ] Encerramento sem culpa
- [ ] Variações
- [ ] Adaptações inclusivas **Bloqueante**
- [ ] Segurança e supervisão **Bloqueante**

## Evidência e linguagem

- [ ] Alegações apontam para IDs da Matriz de Evidências? **Bloqueante se houver alegação**
- [ ] Limitações foram preservadas?
- [ ] O texto evita termos proibidos da política de linguagem? **Bloqueante**
- [ ] O conteúdo evita diagnóstico, terapia ou promessa? **Bloqueante**
- [ ] Benefícios foram substituídos por habilidades/experiências específicas quando possível?

## Revisão

- [ ] Constituição Editorial aprovada
- [ ] Checklist de Segurança aprovado **Bloqueante**
- [ ] Checklist de Acessibilidade aprovado **Bloqueante**
- [ ] Revisão editorial registrada
- [ ] Revisão especializada acionada quando necessária
- [ ] Versão, fontes, revisores e próxima revisão registrados **Bloqueante**
