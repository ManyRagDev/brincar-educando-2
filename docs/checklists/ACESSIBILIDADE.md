# Checklist de Acessibilidade

- [ ] A proposta pode ser compreendida sem depender apenas de fala?
- [ ] Existe alternativa a responder verbalmente?
- [ ] Existe alternativa a apontar/enxergar detalhes?
- [ ] Sons possuem apoio visual/tátil e conteúdo visual possui descrição?
- [ ] Movimento pode ser adaptado para sentado, apoiado, menor amplitude ou imaginação?
- [ ] Materiais podem ser maiores, mais leves, contrastantes ou fixados?
- [ ] A atividade permite reduzir luz, som, textura, cheiro, ritmo e número de estímulos?
- [ ] A criança pode observar sem tocar?
- [ ] Instruções são curtas e podem ser apresentadas uma por vez?
- [ ] Tempo e repetição são flexíveis?
- [ ] A adaptação não cita diagnóstico nem presume incapacidade? **Bloqueante**
- [ ] Há pelo menos duas formas válidas de participação? **Bloqueante**
- [ ] A família é convidada a escolher o que funciona, sem ser responsabilizada por “corrigir” a criança?
- [ ] Imagens, cores, contraste, foco, alvos de toque e texto alternativo atendem à interface?
