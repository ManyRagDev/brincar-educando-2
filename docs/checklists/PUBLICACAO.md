# Checklist de Publicação

## Contrato do conteúdo

- [ ] Todos os campos obrigatórios preenchidos
- [ ] Slug estável e único
- [ ] Faixa etária válida e justificada
- [ ] Status editorial correto
- [ ] Versão incrementada
- [ ] Fontes verificadas relacionadas às alegações
- [ ] Revisores e pareceres registrados
- [ ] Próxima revisão definida

## Gates

- [ ] Constituição Editorial: aprovada **Bloqueante**
- [ ] Checklist específico do formato: aprovado **Bloqueante**
- [ ] Segurança: aprovada **Bloqueante**
- [ ] Acessibilidade: aprovada **Bloqueante**
- [ ] Alegações e linguagem: aprovadas **Bloqueante**
- [ ] Privacidade/ECA Digital: aprovados quando houver funcionalidade digital/dados **Bloqueante**
- [ ] Parecer especializado: aprovado quando acionado **Bloqueante**
- [ ] Piloto/validação: realizado quando exigido pelo protocolo

## Verificação final

- [ ] Conteúdo foi revisado na interface real, inclusive celular?
- [ ] Links e fontes abrem corretamente?
- [ ] Estado vazio/erro/fora da faixa está adequado?
- [ ] Interromper, trocar e voltar são claros?
- [ ] Não há dado familiar em conteúdo, logs ou exemplos?
- [ ] Publicação não amplia catálogo antes de resolver achados bloqueantes?

## Decisão

- [ ] `publicar`
- [ ] `publicar com monitoramento`
- [ ] `ajustes solicitados`
- [ ] `revisão especializada`
- [ ] `arquivar`

Registrar justificativa, responsável e data. Nunca alterar conteúdo publicado materialmente sem nova versão e revisão.
