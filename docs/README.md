## Fluxo mínimo para criar conteúdo

```text
Identificar lacuna do catálogo
        ↓
Ler Constituição + faixa etária + taxonomia
        ↓
Consultar afirmações/fontes necessárias
        ↓
Criar rascunho
        ↓
Aplicar checklist do formato, segurança e acessibilidade
        ↓
Revisão humana e especializada conforme gatilhos
        ↓
Aplicar checklist de publicação
        ↓
Versionar e publicar
```

Nenhuma IA, fonte isolada ou checklist automático substitui a responsabilidade humana pela publicação.
